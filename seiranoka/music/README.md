# Seiranoka music

Upload the three Seiranoka MP3 files into this folder using these exact filenames:

- a-new-page.mp3
- tokyo-in-motion.mp3
- after-class.mp3

Voyage Settings → audio uses `seiranoka/settings-audio.json`.

Custom cues:
- **A New Page** → character-creation
- **Tokyo in Motion** → travel
- **After Class** → contextual friendship / romance / quiet scenes

Combat, near-death, dying, dead, and recovery are intentionally not overridden here so Voyage can keep using its defaults where available.

Raw URLs expected by the JSON:
- https://raw.githubusercontent.com/heezytheg/Hated-Royal/main/seiranoka/music/a-new-page.mp3
- https://raw.githubusercontent.com/heezytheg/Hated-Royal/main/seiranoka/music/tokyo-in-motion.mp3
- https://raw.githubusercontent.com/heezytheg/Hated-Royal/main/seiranoka/music/after-class.mp3
